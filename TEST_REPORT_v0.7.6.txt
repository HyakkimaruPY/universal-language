Factory - Ance v0.7.6 ESTÁVEL — relatório de validação
Base imediata: Factory_Ance_LNReader_v0.7.5_ESTAVEL_Catalogo_Continuidade_Multilingue.zip

OBJETIVO
- impedir o travamento observado ao abrir extensões/catálogos, inclusive ES -> ZH;
- acelerar entrada em extensões já aprendidas;
- tratar WordPress/WooCommerce/LightNovelWP/Madara por família antes do fallback genérico;
- manter as correções de continuidade, deduplicação e isolamento por obra da v0.7.5.

PESQUISA APLICADA
- LNReader multisource/Quickstart: família/CMS -> template específico -> fallback;
- LightNovelWP oficial: rota direta de séries, paginação ?page=N, parsing reduzido/streaming e falha rápida de captcha;
- PR LNORI #2446: TOC recortado + concorrência limitada; 58,3 MB -> 0,4 MB entregues ao parser no benchmark publicado;
- PR Lib-Read #2478: paginação de capítulos controlada para evitar rate-limit;
- MZ Novels: página ativa é validada porque o site pode repetir a última página;
- helper fetch do LNReader: fetchApi repassa init para fetch, permitindo AbortSignal quando disponível.

REGRESSÕES EXECUTADAS
- WooCommerce é detectado e recebe paginação WordPress /page/N/;
- LightNovelWP recebe paginação ?page=N e não é confundido com archive WordPress genérico;
- rota aprendida /page/3/ é normalizada para a raiz do catálogo;
- novelasligeras.net sintético: hot path aprendido faz exatamente 1 request de catálogo;
- cold start sintético: homepage -> link real do catálogo em exatamente 2 requests;
- timeout abortável sinaliza AbortController quando disponível;
- resposta de rede atrasada não entra em compactação/Cheerio após deadline;
- filho não consulta servidor local da Factory para getCurrentProfile/loadTranslationConfig;
- tradução visual de título permanentemente pendente devolve catálogo original dentro do orçamento;
- browse não agenda prefetch escondido de página 2;
- teaser 001..024 + 164..185 continua sendo detectado como incompleto;
- catálogo integral 001..185 continua sendo preferido;
- obra A não fornece catalogUrl/capítulos à obra B;
- single-flight por obra preservado;
- Cloudflare/Turnstile preservados;
- paginação parseNovel/parsePage preservada.
